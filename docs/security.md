# Сетевые функции острова

Чат использует локальное ядро ЛОПАТЫ или передаёт черновик в её окно «Если накипело». Подключения поставщиков моделей и голосовые службы оригинального острова удалены из редакции.

Некоторые функции используют сеть:

- Погода запрашивает поиск города и прогноз у Open-Meteo.
- Поиск текста песни обращается к выбранному источнику и использует данные о треке. Для треков, созданных в ЛОПАТЕ, остров использует сохранённый текст.
- Индикатор обновлений проверяет выпуски ЛОПАТЫ. Обновление устанавливает ЛОПАТА.
- Кнопки ВК и YouTube открывают сайт в браузере. Управление воспроизведением браузера зависит от медиасессии Windows.
