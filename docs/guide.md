# NabyScape — LOPATA Edition

Остров входит в состав ЛОПАТЫ. В выпуске с этим компонентом откройте **Обработка / утилиты → Экран → NabyScape — LOPATA Edition (Остров)**. Окно настроек открывается через кнопку на острове или его значок в трее.

- **Музыка.** В меню источников выберите Коллекцию ЛОПАТЫ, папку или внешнюю медиасессию Windows. Кнопка «Список треков» открывает текущий список. Сердечко добавляет трек в избранное.
- **Чат.** Нажмите маскота или кнопку чата. При закрытой ЛОПАТЕ используется её установленное ядро. При открытой ЛОПАТЕ черновик переносится в «Если накипело». Если другая модель занята, остров спросит, можно ли приостановить задачу.
- **Виджеты.** Выберите их в настройках. Звёздочка рядом с названием назначает виджет, который откроется первым. Настройки положения определяют край экрана и ориентацию острова.
- **Обновления.** Кнопка острова показывает выпуски ЛОПАТЫ. Установка обновления выполняется в ЛОПАТЕ.
